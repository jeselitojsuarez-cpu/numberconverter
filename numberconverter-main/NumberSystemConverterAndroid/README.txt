NUMBER SYSTEM CONVERTER - ANDROID PROJECT

This project wraps the supplied NumberConversion.java logic in a native Android Java UI.

Features:
- Base 2, 8, 10 and 16
- Whole numbers and fractional values
- Superscript exponents such as 2³ and caret notation such as 2^3
- Subscript base notation such as 101101₂ and A3.F₁₆
- Step-by-step output generated by the original converter logic
- Quick symbol buttons for common superscripts/subscripts
- Source/target base dropdowns and Swap button

To build in Android Studio:
1. Open this folder as a project.
2. Allow Gradle/SDK sync to finish.
3. Build > Build APK(s).
4. The APK will normally be under app/build/outputs/apk/debug/app-debug.apk.
